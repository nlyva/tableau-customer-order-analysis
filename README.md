# Customer and Product Order Analysis in Tableau

For a Business Analytics assignment at ADA University, I joined tables
from the OrderDB Excel workbook in Tableau to build two reports.
The reports show order activity from two perspectives: by customer
and by product.

## Tableau Public Reports

1. [Customer Order Report](https://public.tableau.com/app/profile/nazrin.aliyeva/viz/HW4_17616723875580/Sheet1)
2. [Product Order Report](https://public.tableau.com/app/profile/nazrin.aliyeva/viz/HW4_17616723875580/Sheet2)

## Tableau Techniques

- **Data preparation:** Connected Tableau to the OrderDB Excel workbook.
- **Table joins:** Combined related tables using matching fields.
- **Report design:** Built separate worksheets for customer-level and product-level analysis.
